# 上位机通读计划 v1（基于终版 3f905e7）

**目标（完成标志，可检验）**：

1. 附录 B 的 20 个验收问题能**闭卷**答出 ≥18 个；
2. 第 4 轮"13 条红线定位表"全部填满；
3. 三条主链路能徒手画时序图（图标到文件+函数级）；
4. 产出一份"疑点表"（附录 D 模板），全部条目有结论。

**方法（4 条纪律）**：

- **每文件三问**：职责一句话 / 输入输出（信号、参数、返回值）/ 异常边界路径。
- **先文档后代码**：文档写"应该怎样"，代码验证"是否这样"，不一致 → 记疑点表。
- **冒烟当规格**：读一层，对照跑一个冒烟（它们就是可执行的行为规格）。
- **审查三视角**：①闭环（数据流有没有断头）②边界（长度/超时/断连/重复/回绕）③纪律（分层/接线/口径/无效值）。

## 第 3 轮 · 三条链路验证（90 min）

**链路 A（体征）**：断点：parser 喂字节入口 → CM 分发处 → `VitalSignService::processNewData` → `RealtimeMonitorPage::updateVitalSigns`。模拟模式跑一遍，单步两帧。

**链路 B（拍照识别）**：断点：`CM::requestCapture` → `SimulatedDeviceSource`（模拟）/ `WifiHandler::dataReceived`（真机）→ `ImageAssembler::onImageEnd` → `ImageService::onImageReady` → `DietManagePage::onFoodRecognized`。模拟模式 UI 走一遍（你已走通过，这次看数据）；真机 TCP 你已手测过，可跳过。

**链路 C（离线→补传）**：以 `comm_smoke` backlog 段 + 代码走查为主（手动复现成本高）：看门狗判离线 → 回连先 0x05 后更新书签 → 0x04 会话 → 历史帧抑制/去重。

每条链路画一张时序图（纸笔，图标到文件+函数）。

## 第 4 轮 · 红线终检 + 收口（60 min）

13 条红线逐条定位（内容出自交接 §5）：

| #    | 红线                                       | 定位方法                                                     |
| ---- | ------------------------------------------ | ------------------------------------------------------------ |
| 1    | `PAYLOAD_LEN_MAX_IMAGE`=1027               | `protocolparser.h` 常量；comm_smoke "full 1024B payload accepted" |
| 2    | 下行帧 15B 总长/4B 载荷                    | parser 的 build* 函数；comm_smoke "size=15" 断言组           |
| 3    | 图像独立 ProtocolParser                    | CM 里两个 parser 实例，grep `m_imageParser`                  |
| 4    | 模拟模式下行指令路由给模拟器               | CM `sendBandCommand`/`requestCapture` 分支 → `simulator->onHostCommand` |
| 5    | 模拟产图走完整链路                         | `simulateddevicesource.cpp`：组帧→喂图像 parser，不直接 emit imageReady |
| 6    | 不落设备存储/无 OpenCV                     | 全工程 grep `cv::`/`OpenCV` 应为 0；图像只写 `./photos/`     |
| 7    | 识别口径每 100g                            | `imageservice` recognizeFood；`dietmanagepage.cpp` 换算行    |
| 8    | 识别异步                                   | `imageservice.cpp` QNetworkAccessManager 信号式              |
| 9    | 全局提示只走 showGlobalMessage；禁模态阻塞 | `mainwindow.cpp`；`dietmanagepage` 的 showNonModalHint；模态挂起机制 |
| 10   | 分层：View 不直调 DAO/通信                 | 全工程搜：页面文件 include `communication/` 应为 0           |
| 11   | 无效值统一 -1                              | parser 对 0xFFFF 的处理；comm_smoke "invalid weight -> -1"   |
| 12   | ini 键 load/save 同改                      | `appconfigmanager.cpp` 两函数逐键对照                        |
| 13   | 建表以 qrc schema 为准                     | `resources.qrc` :/sql/ + DataManager 执行处                  |

然后：重跑 5 个冒烟 → 疑点表收口（正常/存疑/需改三类）→ 需改项处理。
