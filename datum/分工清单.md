# 亚健康监测系统 — 硬件分工方案

## 一、项目硬件总览

本项目包含 **两个终端设备** + **PC 上位机**：

| 终端 | 主控 | 职责 | 通信方式 |
|------|------|------|----------|
| 智能手环 | ESP32-S3-DevKitC-1 (N16R8) | 心率/血氧、温湿度、拍照识别、振动预警、LCD显示 | WiFi TCP |
| 体重秤 | ESP32-WROOM | 体重采集、去皮、标定 | WiFi TCP |
| PC 上位机 | — | 数据接收、UI显示、健康分析、菜品识别 | WiFi TCP Server |

两个终端都通过 WiFi 连接 PC 端的 `WiFiHandler`（TCP Server），遵循协议 v1.2。

## 四、共用总线约定

两个负责人需要协调的共用资源：

### 1. I2C 总线 (GPIO19/20)
- **你**：MAX30102（心率血氧）
- **搭档**：SHT30（温湿度）
- **约定**：两人同时上电调试时，先各自单独测试，确认地址不冲突（0x57 vs 0x44），再并联

### 2. SPI 总线 (GPIO40/41/42)
- **搭档一人负责**：LCD + 触摸共用，不涉及交叉

### 3. WiFi + 协议
- **你**：手环端 WiFi TCP 客户端
- **你**：体重秤端 WiFi TCP 客户端
- **搭档**：PC 端 WiFiHandler TCP 服务端联调

## 八、关键注意事项

1. **共地**：所有模块必须共地，否则 I2C/SPI 通信乱码
2. **上拉电阻**：I2C 的 SCL/SDA 各需 4.7KΩ 上拉电阻到 3V3
3. **烧录口**：ESP32-S3 用 Micro-USB 口（UART0），不用 USB-C（OTG）
4. **马达驱动**：GPIO 不能直连马达，必须经三极管（S8050）
5. **HX711 供电**：建议 5V，称重更稳定
6. **协议一致性**：两块板子都用协议 v1.2，帧格式统一
