## 一、摄像头 ATK-OV2640

### 模块特性
- 内置 12MHz 有源晶振, **无需 ESP32 提供 XCLK**
- 2×9 排针 (18 脚, 2.54mm)
- 输出格式: YUV422 / RGB565 / JPEG
- SCCB 地址: 0x3C

### 接线表

| ESP32-S3 GPIO | 模块排针 | 信号名 | 说明 |
|---------------|---------|--------|------|
| 3V3 | Pin 1 | VCC | 3.3V 电源 |
| GND | Pin 2 | GND | 地 |
| GPIO16 | Pin 3 | OV_SCL | SCCB 时钟 (I2C) |
| GPIO12 | Pin 4 | OV_VSYNC | 帧同步 (高=场消隐) |
| GPIO17 | Pin 5 | OV_SDA | SCCB 数据 (I2C) |
| GPIO13 | Pin 6 | OV_HREF | 行同步 (高=有效行) |
| GPIO4 | Pin 7 | OV_D0 | 像素数据位 0 |
| GPIO47 | Pin 8 | OV_RESET | 复位 (高电平有效) |
| GPIO5 | Pin 9 | OV_D1 | 像素数据位 1 |
| GPIO6 | Pin 10 | OV_D2 | 像素数据位 2 |
| GPIO7 | Pin 11 | OV_D3 | 像素数据位 3 |
| GPIO8 | Pin 12 | OV_D4 | 像素数据位 4 |
| GPIO9 | Pin 13 | OV_D5 | 像素数据位 5 |
| GPIO10 | Pin 14 | OV_D6 | 像素数据位 6 |
| GPIO14 | Pin 15 | OV_PCLK | 像素时钟 |
| GPIO11 | Pin 16 | OV_D7 | 像素数据位 7 |
| GPIO18 | Pin 17 | OV_PWDN | 掉电控制 (低=使能) |
| **不接** | Pin 18 | NC | 空脚 |
| **不接** | — | XCLK | 模块自带晶振, 无需连接 |

### 配置参数
```c
.pixel_format = PIXFORMAT_JPEG,
.frame_size   = FRAMESIZE_QVGA,   // 240×320, 与 LCD 匹配
.jpeg_quality = 10,               // 0-63, 越小质量越高
.fb_count     = 2,
.fb_location  = CAMERA_FB_IN_PSRAM,
.grab_mode    = CAMERA_GRAB_LATEST,
.xclk_freq_hz = 0,                // 内置晶振, 不输出
.pin_xclk     = -1,               // 不使用
```

## 二、LCD ILI9341 + 触摸 XPT2046 (共用 SPI)

### 模块特性
- ILI9341: 240×320, RGB565, SPI 接口
- XPT2046: 4 线电阻触摸, SPI 接口
- **SPI 总线共用**: 同一 SCK/MOSI/MISO, 不同 CS

### 接线表

| ESP32-S3 GPIO | 模块引脚 | 信号 | 说明 |
|---------------|---------|------|------|
| 3V3 | VCC | 电源 | |
| GND | GND | 地 | |
| **GPIO40** | SCLK (LCD) + T_CLK (Touch) | SPI 时钟 | **共用, 一根线分叉接两个模块** |
| **GPIO41** | MOSI (LCD) + T_DIN (Touch) | SPI 主出 | **共用, 一根线分叉接两个模块** |
| **GPIO42** | MISO (LCD) + T_DO (Touch) | SPI 主入 | **共用, 一根线分叉接两个模块** |
| GPIO48 | CS (LCD) | LCD 片选 | 低有效 |
| GPIO39 | DC (LCD) | 数据/命令 | 0=命令, 1=数据 |
| GPIO21 | RST (LCD) | LCD 复位 | 低有效 |
| 3V3 | BL (LCD) | 背光 | 可串 100Ω 电阻调亮度 |
| GPIO1 | T_CS (Touch) | 触摸片选 | 低有效 |
| GPIO2 | T_IRQ (Touch) | 触摸中断 | 低有效 |

### SPI 配置
```c
#define LCD_SPI_HOST     SPI3_HOST
#define LCD_SPI_FREQ_HZ  (40 * 1000 * 1000)  // 40MHz
```

## 三、MAX30102 心率血氧 (MH-ET LIVE)

### 模块引脚丝印 (实物照片确认)
```
上排 (贴芯片侧): GND  RD  IRD  INT
下排 (贴边缘侧): VIN  SDA  SCL  GND  3V3
```

### 接线表

| ESP32-S3 GPIO | 模块引脚 | 说明 |
|---------------|---------|------|
| 3V3 | VIN | 电源输入 |
| GND | GND | 地 |
| **GPIO20** | SDA | I2C 数据 (与 SHT30 共用) |
| **GPIO19** | SCL | I2C 时钟 (与 SHT30 共用) |
| **不接** | INT | 中断, 用 I2C 轮询 FIFO 代替 |
| **不接** | RD | 红光 LED 测试点 |
| **不接** | IRD | 红外 LED 测试点 |
| **悬空** | 3V3 | LDO 稳压输出, VIN 已接 3V3 时不需使用 |

### 寄存器配置 (商家验证)
```c
REG_INTR_ENABLE_1 = 0xC0;  // FIFO 几乎满 + 数据就绪中断
REG_INTR_ENABLE_2 = 0x00;
REG_FIFO_WR_PTR   = 0x00;  // 清写指针
REG_OVF_COUNTER   = 0x00;  // 清溢出计数
REG_FIFO_RD_PTR   = 0x00;  // 清读指针
REG_FIFO_CONFIG   = 0x0F;  // 采样平均=1, 无翻滚, 几乎满=17
REG_MODE_CONFIG   = 0x03;  // SpO2 模式 (红光+红外)
REG_SPO2_CONFIG   = 0x27;  // ADC=4096nA, 100Hz, 400us 脉宽
REG_LED1_PA       = 0x24;  // 红光 ~7mA
REG_LED2_PA       = 0x24;  // 红外 ~7mA
REG_PILOT_PA      = 0x7F;  // 近距离检测 ~25mA
```

### 算法
- 使用 **Maxim AN5300 官方心率/血氧算法** (纯 C, 平台无关)
- 500 样本滑动窗口 (5 秒 @ 100sps)
- 每 10ms 轮询一个 FIFO 样本
- 峰值检测计算心率, AC/DC 比值查表计算血氧

```c

```

## 五、振动马达

### 电路
```
GPIO15 ──→ 1KΩ 电阻 ──→ S8050 基极 (B)
                           │
                           ├── S8050 集电极 (C) ──→ 马达负极
                           │
GND ─────────────────────── S8050 发射极 (E)

5V ──→ 马达正极
       + 1N4148 续流二极管 (反并联)
```

### 说明
- ESP32 GPIO 不能直接驱动马达, 必须用三极管
- 马达使用 5V 供电
- GPIO15 高电平 → 三极管导通 → 马达振动
- GPIO15 低电平 → 三极管截止 → 马达停止

## 电源分配

| 电源 | 接到 |
|------|------|
| 3V3 | ATK-OV2640 VCC · ILI9341 VCC · XPT2046 VCC · MAX30102 VIN · SHT30 VCC · LCD 背光 |
| 5V | 振动马达正极 (经三极管集电极) |
| GND | 所有模块共地 (必须) |

### 注意事项
1. **所有模块必须共地**, 否则 I2C/SPI 通信会乱码
2. MAX30102 和 SHT30 的 I2C SCL/SDA **各需一个 4.7KΩ 上拉电阻**到 3V3
3. 摄像头电流较大 (峰值可达 100mA+), 确保 3V3 电源能力足够
4. 烧录和供电使用 **Micro-USB 口**, 不要用 USB-C (OTG) 口, 否则 GPIO19/20 与 USB 冲突

## 共用总线说明

### 1. I2C 总线 (GPIO19/20)
```
GPIO19 (SCL) ──┬── MAX30102 SCL (地址 0x57)
                └── SHT30   SCL (地址 0x44)

GPIO20 (SDA) ──┬── MAX30102 SDA
                └── SHT30   SDA
```
两个设备并联在同一总线上, 地址不同不会冲突。

### 2. SPI 总线 (GPIO40/41/42)
```
GPIO40 (SCK)  ──┬── ILI9341 SCLK
                 └── XPT2046 T_CLK

GPIO41 (MOSI) ──┬── ILI9341 MOSI
                 └── XPT2046 T_DIN

GPIO42 (MISO) ──┬── ILI9341 MISO
                 └── XPT2046 T_DO
```
两个设备共用时钟和数据线, 靠各自的 CS 片选区分。

### 3. 3V3/GND
所有模块的 VCC 和 GND 都从 ESP32-S3 排针引出, 可并联分流。

## 引脚冲突检查 (已解决)

| GPIO | 原分配 | 冲突原因 | 解决 |
|------|--------|---------|------|
| 22 | 马达 | SPI flash (DevKitC-1 未引出) | → GPIO15 |
| 38 | LCD CS | v1.1 板载 RGB LED | → GPIO48 |
| 48 | LED | v1.1 板载 RGB LED 在 GPIO38 | → GPIO38 |
| 19/20 | I2C | USB-C OTG D-/D+ | 用 Micro-USB 口烧录, 避开冲突 |
| XCLK | CAM | ATK-OV2640 内置晶振 | → -1 (不接) |
