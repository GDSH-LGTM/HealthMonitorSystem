# 体重秤标定手册

HX711 的输出是 24 位原始 ADC 值，**必须**经过「去皮 + 砝码标定」才能换算成重量。
标定值存在 NVS，掉电不丢；不标定时重量恒为 0，且 0x02 帧的载荷填 `0xFFFF`（无效值），
上位机会显示 `--` 而不是骗人的 `0.00`。

---

## 1. 准备工作

- 秤台装好，传感器四线接到 HX711 的 `E+/E-/A+/A-`
- HX711 的 `DT→GPIO1`、`SCK→GPIO2`（或按 `scale_config.h` 改）
- **一个已知重量的砝码**（推荐 500g 或 1kg；用厨房秤称过的物体也行）
- 串口终端（`.\flash.ps1 monitor`）

## 2. 标定流程（3 步）

```
① 空载，按 t         → 去皮，把当前读数记为零点
② 放上砝码，按 c500  → 用 500g 砝码标定（数字换成你的砝码克数）
③ 按 s               → 查看状态确认
```

### 具体操作

**第 0 步：确认能读到数据**

按 `r`，应看到类似：

```
I (12345) main: 原始值 #1: 8432100   (克≈0.0)
I (12545) main: 原始值 #2: 8431980   (克≈0.0)
```

- 若打印 `读取失败` → HX711 没连上/没供电/DOUT 与 SCK 接反
- 若 5 个原始值**完全一样**且不随按压变化 → 传感器没接好（E+/E-/A+/A- 四线）

**第 1 步：去皮（空载）**

确保秤台**空着**，按 `t`：

```
I (20000) main: 去皮中（请确保秤台空载）…
I (20200) main: 去皮完成：offset = 8432050
I (20200) main: 标定值已保存到 NVS：offset=8432050 scale=0.000000
```

**第 2 步：砝码标定**

放上**已知重量**的砝码，等读数稳定，按 `c500`（若砝码是 500g）：

```
I (30000) main: 标定中（请已放好 500.0 g 砝码）…
I (30200) main: 标定完成：raw=8512300 offset=8432050 → scale=0.062328 g/LSB
I (30200) main: 标定值已保存到 NVS：offset=8432050 scale=0.062328
```

**第 3 步：确认**

按 `s`：

```
I (40000) main: ──────── 状态 ────────
I (40000) main: 重量      : 500.2 g (0.500 kg)
I (40000) main: 标定      : offset=8432050  scale=0.062328 g/LSB
I (40000) main: 稳定      : 是 (连续命中 3/3)
I (40000) main: WiFi      : 已连接
I (40000) main: TCP 通道  : 已连接 (PC 192.168.43.190:45679)
I (40000) main: 统计      : 采样 512 次 / 读数失败 0 次 / 已上报 1 帧 / 重连 1 次
```

重量应接近砝码实际值（±10g 内正常）。

---

## 3. 命令速查

| 命令 | 作用 |
|---|---|
| `t` | 去皮：把当前读数记为零点并存 NVS |
| `c<克数>` | 砝码标定，例如 `c500`、`c1000` |
| `r` | 打印 5 组原始 ADC 值（排查接线/漂移用，不看标定） |
| `s` | 打印状态（重量、标定值、稳定、连接、统计） |
| `h` | 帮助 |

> 命令通过 **UART0（COM 口）** 输入，和日志共用同一个串口。
> `.\flash.ps1 monitor` 里直接敲字符即可（需要回车）。

## 4. 精度与稳定性

当前参数在 `scale_config.h`：

```c
#define SCALE_SAMPLE_PERIOD_MS   80     /* 采样周期 */
#define SCALE_STABLE_WINDOW      6      /* 最近 6 个样本 */
#define SCALE_STABLE_TOLERANCE_G 15.0f  /* 窗口内极差 ≤ 15g 视为稳定 */
#define SCALE_STABLE_REQUIRED    3      /* 连续 3 次稳定判定才算稳定 */
#define SCALE_MIN_GRAMS          200.0f /* 小于 200g 视为空载，不上报 */
```

### 调参建议

| 现象 | 调整 |
|---|---|
| 读数跳动大、迟迟不稳定 | 调大 `SCALE_STABLE_TOLERANCE_G`（如 30）或调大 `SCALE_STABLE_WINDOW` |
| 明明稳了却不上报 | 调小 `SCALE_STABLE_REQUIRED`；确认重量 > `SCALE_MIN_GRAMS` |
| 上报太频繁（放东西就报） | 调大 `SCALE_STABLE_REQUIRED` |
| 小重量测不出来 | 调小 `SCALE_MIN_GRAMS`（注意噪声也会被当有效重量） |
| 称重值系统性偏大/偏小 | 重新标定；或用**更大**的砝码标定（相对误差更小） |

### 已知误差来源

- **协议量化**：载荷单位是 0.01kg = 10g，所以最大量化误差 ±5g。自测里已验证往返误差 ≤ 0.005kg
- **HX711 噪声**：默认 10Hz 输出、增益 128，典型有效位数约 16~18 位
- **温漂**：长时间使用后零点可能漂移，重新按 `t` 去皮即可
- **传感器安装**：四角受力不均会带来非线性误差，尽量让重物居中

---

## 5. 清零与重标定

- **只清零点**（换了位置/温度变了）：空载按 `t`
- **完全重标**：空载按 `t` → 放砝码按 `c<克数>`
- **清掉 NVS 里的标定值**（恢复出厂）：`.\flash.ps1 erase-flash` 后重新烧录

---

## 6. 排查表

| 现象 | 可能原因 |
|---|---|
| `r` 打印"读取失败" | HX711 供电、DOUT/SCK 接反、DOUT 未上拉 |
| `r` 的 5 个值完全一样且按压无变化 | 传感器 E+/E-/A+/A- 没接好 |
| `c` 报"放砝码前后读数无变化" | 砝码没放上去，或传感器没接好 |
| 重量是负数且绝对值很大 | 传感器 A+/A- 接反（不影响使用，重新标定即可） |
| 重量一直是 0 | 未标定（看 `s` 里的"标定"行，scale=0 就是没标） |
| 标定后重启又变 0 | NVS 没写成功（看日志有没有"标定值已保存到 NVS"） |
